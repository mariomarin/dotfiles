# nushell-lsp

Claude Code plugin for the language server built into Nushell (`nu --lsp`). Covers `.nu` files.

```bash
claude plugin marketplace add ~/.local/share/chezmoi
claude plugin install nushell-lsp@dotfiles
```

See [Nushell LSP](https://www.nushell.sh/blog/2023-11-14-nushell_0_87_0.html) and
[Claude Code plugins](https://docs.claude.com/en/docs/claude-code/plugins-reference#lsp-servers).
